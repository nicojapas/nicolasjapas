# Nicolás Japas - Official Website

This is the static HTML version of nicolasjapas.com, designed for deployment on GitHub Pages.

## Features

- **Responsive Design**: Mobile-friendly layout
- **Dark Theme**: Black background (#08080a) with red accents (#ad0303)
- **Sections**:
  - Home: Blog posts and latest updates
  - Music: Tango Solista, Mr. Tofu, Astra Noctis, Conurbano Tango
  - Illustrations: Political and artistic illustrations
  - About: Biography and background
  - Photos: Professional photography by Santiago Casal
  - Contact: Email and social media links

## Technologies

- Pure HTML5, CSS3, and vanilla JavaScript
- Font Awesome icons
- Responsive grid layouts
- Smooth scrolling navigation

## Local Development

Simply open `index.html` in your browser or use a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`

## GitHub Pages Deployment

1. Push this repository to GitHub
2. Go to Settings → Pages
3. Select branch `main` and folder `/ (root)`
4. Your site will be live at `https://[username].github.io/nicolasjapas/`

## Customization

- Update social media links in `index.html`
- Add YouTube video IDs for embedded videos
- Replace Spotify artist URL with actual link
- Modify content in each section as needed
